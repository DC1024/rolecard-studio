DOCKER · AMD64 / ARM64

多架构 Docker 一键部署

适配 NAS（威联通 / 群晖 / 极空间）与自建服务器，持久化挂载数据库、`.master.key` 密钥与立绘资产。 

docker run -d --name rolecard-studio \
  --restart unless-stopped -p 3000:3000 \
  -v rolecard_data:/app/data \
  -e ROLECARD_ADMIN_USER=admin \
  -e ROLECARD_ADMIN_PASSWORD=<your-strong-password> \
  ghcr.io/dc1024/rolecard-studio:latest
