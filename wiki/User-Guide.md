# 详细功能使用指南

本文档按 **`v1.6.0`** 实际界面结构与功能模块，逐项说明 RoleCard Studio 的全部交互功能与使用技巧。

---

## 1. 工作台界面布局与外观定制

### 1.1 顶栏居中导航与左侧检索栏

- **顶部导航栏（居中单行布局）**：
  - 左侧：侧边栏折叠开关、**RoleCard Studio Logo**（点击可随时返回角色卡库）。
  - 中央居中导航：**角色卡库** | **生成新卡** | **快速试聊** | **世界书** | **插件与 MCP** | **审核与同步** | **导入旧卡升级**。
  - 右侧：系统设置、主题切换、字号调整、账号登录/退出。
  - *注：「卡片详情」不再作为常驻顶栏项，点击画廊或侧栏中的任意角色卡即可进入详情页，并可在详情页顶部一键返回角色卡库。*
- **左侧边栏（固定 `276px` 宽，支持一键折叠）**：
  - 保留实时关键词搜索框（匹配角色名、作品名与标签）。
  - 规格筛选（全部 / AI 角色扮演 / TRPG CoC / TRPG D&D / 通用）与生成模式筛选（Mode A / B / C）。
  - 常用标签胶囊一键过滤，底部列表展示 `2:3` 迷你缩略图与版本号。
- **角色卡库画廊（默认主视图）**：
  - 响应左侧边栏的搜索、筛选与标签条件，实时以 `2～5` 列网格展示所有角色卡的 `2:3` 竖版立绘封面。
  - 每张卡片展示规格徽标、是否已裁剪 `1:1` Token 标识、版本号与快捷 **「快速试聊」** 入口。

### 1.2 主题与独立字号缩放

- **5 种主题模式**：`极简晨白 (light)`、`深邃夜幕 (dark)`、`极客青蓝 (ocean)`、`羊皮暖卷 (parchment)`、`跟随系统 (system)`，切换状态持久化至浏览器 `localStorage`。
- **独立字号缩放（`12px–22px`）**：提供「小 (`14px`) / 中 (`16px`) / 大 (`18px`)」预设及滑块精确调节；采用布局解耦缩放设计，放大正文阅读字号时不会破坏顶栏与滑块布局。

## 2. 角色卡生成引擎

### 2.1 三种核心生成模式（Mode A / B / C）

| 模式 | 数据来源 | 适用场景 | 考据保障 |
| --- | --- | --- | --- |
| **Mode A（仅参考材料）** | 手动输入文本、上传 `.txt`/`.md`/`.json` 文件、直链 URL、AI 识图反推描述 | 原创 OC、私人设定集、本地小说人物 | 严格基于提供材料提纯，不主动联网发散 |
| **Mode B（仅联网检索）** | 自动调用 Layer-1 公开百科（萌娘/PRTS/Wikipedia）及配置的 Layer-2 搜索引擎 | 动漫、游戏、历史、公开 IP 角色 | **硬拦截机制**：若未检索到有效参考资料，拒绝生成并提示补充材料或切换模式 |
| **Mode C（混合模式）** | 本地参考材料（第一优先级骨架）+ 联网补充检索 | 已有大纲/草稿但需补全细节的二创或改编角色 | 所有字段按双源溯源标记（`user_provided` / `search_supplement`） |

### 2.2 实体类型与规格预设

- **规格预设**（位于「生成新卡」表单顶部）：
  - **AI 角色扮演**：强化开场白（`first_mes`）、备选开场白（`alternate_greetings`）、对话示例（`mes_example`）与防出戏系统指令（`system_prompt`）。
  - **TRPG 车卡**：支持 CoC 7e 与 D&D 5e，生成基础背景的同时自动或按需推演真实规则数值面板。
  - **通用设定**：输出客观精炼的人物结构化档案，适合小说创作与设定集归档。
- **实体类型**：
  - `虚构角色 (fictional)`：常规创作与演绎角色。
  - `真实人物 (real_person)`：生成时保持客观中立考据，**元舆论风评层默认关闭**（不主动注入外界口碑争议），用户可在详情页「定时演化」标签按需自主开启或编辑。

### 2.3 生成进度流与安全防护

- 生成过程通过 SSE 实时推送 5 个阶段状态（`材料准备 → 百科考据 → 模型推演 → Schema校验 → 保存入库`），支持展示推理模型的 `<think>` / `<thought>` / `<reasoning>` / `reasoning_content` 思考内容。
- 若提供参考 URL（最多 5 条），服务端会自动经过 **SSRF 防护**（拦截私网 IP、回环地址及非 HTTP(S) 协议）并使用 Readability 抽取正文；同时内置材料 Token 总预算封顶，避免超大规模百科资料撑爆模型思考配额。

## 3. 角色卡编辑、引用扩充、单区块生成与 Token 优化

在详情页中可以对角色卡进行精细化管理：

1. **结构化编辑**：支持修改名称、简介（`summary`）、性格（`personality`）、外貌（`appearance`）、背景（`background`）、说话风格（语气/口头禅/习惯）、人际关系表、场景、开场白、备选开场白、对话示例、系统提示词与标签。
2. **字段锁定（`lockedFields`）**：可勾选锁定任意字段（如锁定 `first_mes` 或 `appearance`）。无论后续执行「AI 微调」、「单区块 AI 生成」还是「Token 预算压缩」，被锁定字段都会被程序级原样保留。
3. **顶部「AI 微调（Refine）」与实时思考流**：输入自然语言修改要求（如「把说话语气改成更冷淡克制，增加两条口头禅」），点击「AI 微调」即可通过 SSE 实时查看阶段进度与模型思考过程，自动生成新版本并计算变更摘要（`diffSummary`）。
4. **单区块「AI 生成」与实时思考流**：在「核心设定与外貌」「开场白与提示词」页签的任意可生成区块（简介、性格、外貌、背景、场景、语言风格、人际关系、开场白、对话示例、系统提示词、作者备注、备选开场白）点击 **「AI 生成」**，系统将在对应区块内实时展示进度与可折叠思考过程，结合角色卡完整上下文与引用资料单独重写该字段。
5. **已有角色卡引用扩充与联网搜料（「引用溯源」页签）**：
   - 支持 **联网搜料**（自定义检索关键词，调用 Layer-1 公开百科与 Layer-2 搜索引擎预览结果，勾选后入库）、**粘贴文本设定** 与 **抓取网页 URL**（自动经过 SSRF 防护与 Readability 正文提纯），并可随时删除无用或过期引用。
   - 每条引用支持 **复选框勾选**（新添加的引用自动勾选）：在顶部「AI 微调」或任意区块点击「AI 生成」时，优先按勾选的引用条目注入提示词；若未勾选，默认倒序优先选用最新补充的最多 6 条参考资料。
6. **Token 预算压缩（Compress）**：设定目标 Token 上限（`150–8000`），由主模型在尽量保留核心性格与关系的前提下精简冗余描写，实测对比压缩前后的 Token 计数。

## 4. 立绘与 1:1 VTT Token 工作流

全站角色卡统一以 **`2:3` 竖版比例** 展示立绘封面，所有其他比例需求（如 `1:1` VTT Token）均由 `2:3` 主立绘衍生而来：

1. **2:3 上传裁剪**：
   - 选择本地 PNG / JPG / WebP 图片，在交互式裁切框中拖动/缩放取景，确认后在浏览器端以 `600×900` 固定分辨率导出并上传保存。
   - **同步衍生 1:1 Token**：上传裁剪界面内置实时 `1:1` 虚线框与圆形 Token 预览（默认靠上头肩取景，避免切头），可在上传 `2:3` 立绘的同时一键保存 `512×512` 的 `1:1` Token 与归一化裁剪坐标（`{ x, y, size }`）。
2. **AI 生图（固定 `1024×1536` 逻辑画幅，多协议自动适配）**：
   - 需先在「设置 → 模型槽位」中配置独立的 **生图模型（Image Model）**，可直接使用「智谱免费全家桶」「魔搭每日免费」「硅基流动 + Kolors」等一键预设中的生图槽位。
   - 底层自动适配 **OpenAI、智谱 CogView、硅基流动（Kolors / Qwen-Image 自动映射兼容竖版尺寸）与魔搭 ModelScope（自动异步轮询任务状态）** 四种接口协议，并透传 **反向提示词（`negativePrompt`）** 给支持该参数的引擎（如硅基流动、魔搭）。
   - 若上游只返回短效外链 URL，服务端会自动通过 `llm_image` 同源代理拉取并转为 `dataUrl` 返回，避免外链 1 小时过期或跨域失败。
   - 内置 **8 种画风预设**：包含 **「空白预设（自由发挥）」**（不注入固定画风，完全由画面要求或草稿决定）、**「写实摄影人像」**，以及日系二次元、半厚涂、古典油画、水彩、复古赛璐璐、暗黑哥特。
   - 支持 **多套风格预设管理**：可展开编辑画风描述词/反向词参考/默认画面要求并即时试用，支持 **新建空白、修改保存、另存为、重命名、删除自定义风格**（按登录用户隔离，内置预设全站共享且支持直接修改后 **一键恢复默认**）。
   - 支持 **结合当前角色卡自动生成英文生图提示词** 或 **对已有草稿提示词进行 AI 优化**，并自动将最终提示词回写保存至角色卡 `imagePrompt`。
   - 生图完成后点击应用，前端自动生成 `600×900` `2:3` 主立绘与默认头肩 `512×512` `1:1` Token 上传入库。
3. **搜图代理（Wikimedia Commons）**：
   - 输入角色名或关键词搜索公开可用图片（遵循 `media` 代理配置），缩略图经服务端同源代理 `/api/v1/images/proxy` 加载展示（避免浏览器直连外网图床被分流/限流/CORS 拦截）。
   - 点击任一搜索结果后，系统自动经同源代理拉取原图（若超时或超限则回退缩略图），在浏览器端生成 `600×900` `2:3` 主立绘与默认 `512×512` `1:1` Token 并持久转存至本地 `/uploads/`。
4. **独立调整 1:1 Token**：
   - 在详情页点击 **「1:1 Token」** 按钮（或点击 Token 圆形微缩预览），弹窗自动通过同源代理 `/api/v1/cards/:id/portrait-source` 拉取原立绘（彻底规避第三方防盗链或 CORS 画布污染），拖拽蓝色取景框即可独立更新 `tokenImageUrl` 而不破坏原 `2:3` 封面。

## 5. 独立世界书（Lorebook）与快速试聊沙盒

### 5.1 世界书管理

- 支持创建多本独立世界书，配置全局参数：`scanDepth`（扫描深度）、`tokenBudget`（Token 预算上限）与 `recursiveScanning`（递归扫描）。
- 每本世界书可包含多条词条（Entry）：
  - **蓝灯词条（`constant: true`）**：常驻生效，只要关联该世界书即无条件注入上下文。
  - **绿灯词条（`constant: false` / `selective: true`）**：按主关键词（`keys`）和次级关键词（`secondary_keys`）匹配最近对话历史后动态触发。
  - 支持配置注入位置（`before_char` / `after_char`）与插入优先级（`insertion_order`）。
- 一本世界书可关联多张角色卡，一张角色卡也可同时关联多本世界书；导出 CCV3 时自动去重合并为 `character_book`。

### 5.2 快速试聊沙盒（Playtest）

- 无需切到外部酒馆即可在线测试角色卡表现：
  - 选择测试 **开场白**（主开场白或任意 `alternate_greetings`）。
  - 自定义测试者称呼（默认 `旅行者`）与测试人设（`userPersona`）。
  - 支持 **临时模型覆盖（`modelOverride`）**，在不改动系统设置的前提下临时切换模型测试效果。
  - **蓝/绿灯命中调试区**：每轮回复后清晰展示触发了哪本世界书的哪条词条、属于蓝灯常驻还是绿灯关键词命中、具体匹配到了哪个词。
  - **采纳为对话示例**：看到满意的一轮问答，点击「采纳至 `mes_example`」即可直接沉淀进角色卡示范对话中。

## 6. 定时演化、单跳涟漪与审核同步中心

### 6.1 定时演化调度（默认关闭）

- 进入详情页的调度设置可为单张角色卡开启定时演化：
  - `enabled`：默认 `false`，需显式开启。
  - `intervalDays`：检查周期（`1–365` 天，默认 `7` 天）。
  - `syncScope`：`canon`（原作设定同步）、`meta_reputation`（玩家口碑/外部评价摘要）、`both`（两者；其中现实/历史人物卡默认关闭风评注入，可按需自主开启）。
  - `autoApplyThreshold`：`manual_review`（一律进审核队列，推荐）或 `auto_minor`（极小改动自动应用，重大设定仍进人工审核）。
- 也可手动点击「立即触发一次演化检查」，不必等待周期到达。

### 6.2 单跳关系涟漪（1-Hop Ripple）

- 当某张角色卡发生背景演化并变更人物状态/关系时，系统仅沿 **共享同一本世界书的直接相邻角色（1-Hop）** 推演关系态度变更提案（绝不无边界递归扩散）。
- 所有涟漪提案统一进入顶栏 **「审核与同步」** 队列，需人工点击 **「批准」** 或 **「驳回」** 后才会修改目标角色卡的 `relationships`。

## 7. 全格式导出中心

在角色卡详情页 **「导出中心」** 支持以下 8 种标准导出格式：

| 格式标识 | 说明与典型用途 |
| --- | --- |
| `tavern_png` | SillyTavern CCV3 标准 PNG 卡（自动将 CCV3 JSON + 合并后的世界书写入 PNG 元数据块；优先使用已上传 PNG 底图） |
| `tavern_v3_json` | 纯 SillyTavern `chara_card_v3` JSON（含合并 `character_book` 与 `sources`） |
| `json` | RoleCard Studio 内部结构化 `RoleCardContent` 原始 JSON |
| `markdown` | 人类可读的完整设定文档（含元数据、性格、背景、开场白与溯源清单） |
| `vtt_token_png` | 直接下载裁剪好的 `1:1` VTT Token 头像图片（若未单独裁剪则回退至 `2:3` 立绘或默认占位图） |
| `foundry_dnd5e_json` | Foundry VTT D&D 5e 系统 Actor 导入 JSON（自动优先绑定 `tokenImageUrl` 作为 Actor 贴图） |
| `trpg_sheet_html` | 可直接浏览器打开打印的排版精美跑团车卡表（支持 CoC 7e / D&D 5e） |
| `trpg_sheet_md` | Markdown 格式跑团车卡表，适合粘贴到跑团日志或 Notion/Obsidian |

> 此外，在 **「插件与 MCP」** 中还可以调用已启用的导出格式化声明式插件（如 Obsidian 双链人物笔记 `.md`、Ren'Py 角色定义脚本 `.rpy`）。
