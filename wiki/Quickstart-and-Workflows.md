# 快速入门与典型场景

本指南面向首次使用 **RoleCard Studio** 的用户，带你从首次登录完成初始化，并通过 **4 个典型实战场景** 快速掌握全链路能力。

---

## 第一步：首次启动与管理员登录

1. 打开浏览器访问 `http://127.0.0.1:3000`（源码开发前端模式为 `http://localhost:5173`）。
2. 默认站点访客策略为 **`public`（可浏览只读卡片）**，若要创建、编辑、试聊或配置模型，请先登录管理员账号：
   - **情况 A**：启动时传入了 `ROLECARD_ADMIN_USER` 与 `ROLECARD_ADMIN_PASSWORD` 环境变量，直接使用你设定的账号密码登录。
   - **情况 B**：未显式传入密码，服务首次初始化数据库时会自动生成随机密码，并在控制台输出如下日志：
     ```text
     [RoleCard Studio] Initial admin account created -> username: "admin", password: "<随机密码>" (please change it after login)
     ```
3. 点击右上角 **「登录」** 按钮完成登录，随后点击 **「设置 → 账号安全」** 修改为自己的常用管理员密码。

---

## 第二步：配置至少一个主大模型（Primary LLM）

1. 点击右上角 **「设置」**，在 **「模型槽位」** 页签顶部可直接点击 **「新手免费源站一键向导」**，或手动配置 **主生成模型（Primary LLM）**。
2. 推荐使用以下开箱即用的配置方式之一：
   - **一键免费全家桶（强烈推荐新手）**：
     - **智谱免费全家桶**：1 个智谱 BigModel 免费 Key 即可同时跑通建卡（`glm-4.7-flash`）、试聊、识图（`glm-4.6v-flash`）与生图（`cogview-3-flash`）全部 4 个槽位，国内直连无需代理。
     - **魔搭 ModelScope 每日免费方案**：绑定阿里云后可免费使用 `Qwen2.5-72B`、视觉识图与 `Qwen-Image` 异步生图。
     - **硅基流动 / OpenRouter / Groq / Gemini**：支持 8B 永久免费与海外 `:free` 模型，可通过模型输入框下方的推荐芯片快速切换；同服务商多槽位可点击 **「同步到同服务商其它槽位」** 一键复用 API Key。
   - **云端高性价比付费方案**：选择 `DeepSeek`（默认 `https://api.deepseek.com/v1`、`deepseek-chat` 或 `deepseek-reasoner`）、`硅基流动 (SiliconFlow)`、`Kimi` 或 `通义千问`。
   - **纯本地零成本方案**：选择 `本地 Ollama`（默认 `http://127.0.0.1:11434/v1`、无需 API Key，填写本机已拉取的模型名如 `qwen2.5:14b`）。
3. 点击 **「测试连接」** 按钮：界面会通过 SSE 实时输出连接进度、模型思考流（若有）与验证结果（生图槽位探测兼容智谱/硅基/魔搭异步队列），确认绿色通过后点击 **「保存配置」**。

## 典型场景实战

### 场景 1：零外部 Search Key 联网考据生成 SillyTavern CCV3 角色卡

**适用对象**：想快速生成已知动漫/游戏/小说/历史角色，并直接导入 SillyTavern 使用的玩家。

1. 点击顶栏居中导航的 **「生成新卡」**。
2. 在表单头部规格切换栏选择 **「AI 角色扮演」**。
3. 填写表单：
   - **生成模式**：选择 **Mode B（仅联网检索考据）**
   - **实体类型**：虚构作品角色选择 `虚构角色 (fictional)`
   - **角色名称** / **所属作品**：例如 `凯尔希` / `明日方舟`
4. 点击 **「开始生成」**，实时观察 5 阶段进度条（`材料准备 → 百科考据 → 模型推演 → Schema校验 → 保存入库`）。  
   *内置 Layer-1 引擎会自动免 Key 检索 PRTS Wiki / 萌娘百科 / Wikipedia 并附带可追溯引用来源。*
5. 生成完成后自动跳转至详情页：
   - 在 **「快速试聊」** 中验证开场白与说话腔调。
   - 点击 **「2:3 立绘」** 上传或 AI 生图（固定 `1024×1536`），系统自动保存 `2:3` 主立绘与衍生 `1:1` Token。
   - 在 **「导出中心」** 点击 **`SillyTavern CCV3 PNG`**，即可下载带完整 JSON 元数据与嵌入头像的 `.png` 卡片，直接拖入 SillyTavern！

### 场景 2：从本地设定文档 / 参考图创作原创 OC 并绑定世界书

**适用对象**：原创小说作者、AI RP 作者或世界观设定师。

1. **创建独立世界书**：
   - 点击顶栏 **「世界书」** → 新建世界书（如《新海都市设定集》）。
   - 添加若干词条：
     - **蓝灯词条（Constant = true）**：全剧常驻世界观基调、通用法则（每次对话必然注入）。
     - **绿灯词条（Selective = true，填写触发关键词如 `黑市,义体`）**：仅当聊天内容提到对应关键词时按 `scan_depth` 注入。
2. **生成原创 OC 角色卡**：
   - 点击顶栏 **「生成新卡」**，选择 **Mode A（仅参考材料）** 或 **Mode C（本地骨架 + 联网考据）**。
   - 将你的 `.txt` / `.md` 设定文档直接上传解析到参考材料框，或上传一张参考图并点击 **「AI 识图反推外貌」**（若配置了 Vision 槽位会自动使用识图模型）。
   - 在 **「关联世界书」** 中勾选刚才创建的《新海都市设定集》，提交生成。
3. **验证蓝/绿灯触发**：
   - 切到 **「快速试聊」**，在测试消息中故意提及关键词（如 `我们去黑市看看吧`），在右侧/下方命中调试面板即可直观看到绿灯词条被点亮命中。

### 场景 3：TRPG 跑团车卡 + 2:3 头像裁出 1:1 VTT Token

**适用对象**：CoC 7e、D&D 5e 主持人（KP/DM）与跑团玩家。

1. 点击顶栏 **「生成新卡」**，在规格切换栏选择 **「TRPG 车卡」**（可选 **CoC 7e 调查员** 或 **D&D 5e 冒险者**）。
2. 输入人物背景与职业构想并生成角色卡。
3. 进入详情页后，系统已生成（或点击面板中的重新推演）真实规则数值面板：
   - **CoC 7e**：STR/CON/SIZ/DEX/APP/INT/POW/EDU、HP/MP/SAN/DB、核心技能表。
   - **D&D 5e**：STR/DEX/CON/INT/WIS/CHA、AC/MaxHP/Proficiency、特质与背景。
4. **制作 VTT 头像 Token**：
   - 先通过 **「2:3 立绘」** 为角色配置竖版立绘。
   - 点击详情页的 **「1:1 Token」** 按钮进入独立裁剪视图，拖拽蓝色正方形取景框对准角色头肩部位（支持滚轮/滑块缩放），保存 `512×512` PNG。
5. **一键导出到跑团工具**：
   - 导出 **`Foundry VTT D&D 5e Actor JSON`**（自动优先引用 `1:1` Token 作为 Actor 与原型 Token 贴图）。
   - 导出 **`1:1 VTT Token 头像 (.png)`** 直接用于 Roll20 / Foundry / Owlbear Rodeo。
   - 导出 **`跑团车卡表 (HTML / Markdown)`** 离线打印或分享给队友。

### 场景 4：导入旧版 PNG / JSON 角色卡升级并锁定核心字段

**适用对象**：手头已有大量旧版 Tavern V1 / V2 卡片，希望升级为 CCV3 并批量微调的玩家。

1. 点击顶部居中导航右侧的 **「导入旧卡升级」** 按钮。
2. 选择本地 `.png`（自动解析 `tEXt` / `iTXt` 中的 `ccv3` 或 `chara` Base64 数据块）或 `.json` 文件，选择目标规格并勾选是否同时导入内嵌世界书。
3. 导入后进入详情页，对于不希望后续 AI 微调或压缩改动的核心字段（例如 `first_mes`、关键 `personality` 段落），点击字段旁的 **🔒 锁定图标** 加入 `lockedFields`。
4. 随后可以放心地使用 **「AI 微调」** 或 **「Token 预算压缩」** 优化冗余描述——被锁定的字段将被严格原样保留，每次修改都会生成独立版本和 Diff 摘要。
